# KHL Manager — браузерный хоккейный менеджер

## Запуск локально
Откройте `index.html` в браузере. Сборка и сервер не нужны.

## Публикация на GitHub Pages
1. Создайте публичный репозиторий на GitHub.
2. Загрузите `index.html` и `README.md` в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
6. Через минуту сайт появится по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Сохранения
Карьера хранится в `localStorage` браузера на конкретном устройстве. Для переноса на другое устройство понадобится экспорт/импорт сохранения (можно добавить следующим обновлением).

## Что есть в первой версии
- выбор из 22 клубов и старт карьеры;
- главная страница, новости, обмены, состав, тренировки, штаб, система, лига;
- симуляция матчей, таблицы, бюджеты и рейтинги;
- сохранение карьеры в браузере.

Составы, рейтинги и бюджеты являются условными игровыми данными. Эта версия — рабочий прототип; отдельные правила КХЛ и полный календарь/плей-офф можно углублять итерациями.
